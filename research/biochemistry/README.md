# Biochemistry research and archived examples

These files are retained for review and provenance. Startup and MRST module
activation do not add this directory to the MATLAB path.

- `archive/legacy-examples`: former `h2-biochem/examples/trash` scripts.
- `3d`: former `h2-biochem/examples/3D_experiments` studies and figures.

Run `startupH2sim` first, then add only the selected study folder explicitly.
These cases are not part of the supported introductory workflow. Moving them
does not establish numerical correctness or manuscript inclusion. Supported
example names and runtime model class locations are unchanged.
