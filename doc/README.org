* H2sim documentation

The website contains code documentation and selected runnable examples.

** Build

From the repository root:

#+begin_src shell
python -m pip install -r doc/requirements.txt
python -m sphinx -W --keep-going -b html doc build/docs
python tools/check_documentation.py build/docs
python -m http.server 8000 --directory build/docs
#+end_src

Open http://localhost:8000. Notebook execution is disabled in the website build;
run MATLAB examples locally and explicitly update selected figure assets.

** Content

The main model sections are black-oil storage in saline aquifers, compositional
flow with bacterial effects, and PHREEQC coupling. Installation/dependencies,
thermodynamics, selected examples, and reference information have separate pages.

Do not add manuscripts, unpublished research results, field-cycle experiments,
or generated simulation archives to the documentation source.

** CI

Pull requests build the documentation and upload a preview artifact. Only a
push to master publishes the site through the GitHub Pages workflow.

** Onboarding and verification

Keep README.md, installation.rst, quickstart.rst and dependencies.rst aligned
when changing startup or example options. verification.rst records dated local
MATLAB checks separately from documentation CI. Do not label an untested
platform or MATLAB release as verified. Update CITATION.cff from agreed project
credits and retain dependency and dataset attribution.
