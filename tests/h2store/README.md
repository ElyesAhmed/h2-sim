# Local h2-store checks

From MATLAB at the H2sim repository root:

```matlab
addpath(fullfile(pwd, 'tests', 'h2store'));
results = runH2StoreTests();
```

Initialize the pinned MRST submodule first, or pass that checkout to
`runH2StoreTests('/path/to/mrst')`. These tests run locally, without PHREEQC,
network access, plots or GitHub MATLAB CI. The test folder stays outside the
module runtime path. The runner restores the MATLAB path and working folder.

## Coverage

- Henry–Setschenow: zero pressure, pressure scaling, salting-out and table units.
- Hydrogen Z: zero-pressure limit and vector/scalar consistency.
- Storage schedules: consecutive equal stages, repeated cycles, final stage,
  first-well name fallback, empty and single-stage schedules.
- Frozen property values and two four-cell, two-step oil-gas simulations:
  boundary-driven injection and closed-domain pressure redistribution.
  Both use local generated SGOF tables and the local hydrogen Z correlation.
  They compare every accepted state's pressure and saturation, and check
  positive pressure and physically bounded phase fractions.

## References and limits

`reference-solutions.json` records results from the unmodified h2-store at
`e58f5a8a823dd54c0688165f1b6ecd85ce7a12f8`, before this cleanup. References
are deliberately not regenerated by the test runner. Updating them requires
reviewing the numerical change and recording its reason and provenance.
Pressure tolerances are 0.01 Pa absolute and 1e-9 relative; saturation
tolerances are 1e-9 absolute and 1e-7 relative. Property tolerances are 1e-12
relative. References detect change; they are not independent physical validation.

The simulations use immiscible `GenericBlackOilModel`, constant temperature,
and zero gravity. Dissolution, vaporization, hysteresis, full aquifer setups,
PVT-file generation, and paper figures need separate coverage. In particular,
the gas-inventory formulas in `computeGasVolumes` need an accounting audit
before being accepted as reference values. These tests do not certify that
utility or the Rowe–Chou density implementation.
